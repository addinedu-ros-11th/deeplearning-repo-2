SLIDE 01

프로젝트 핵심 소개 (Overview)

  • "누구인가?": InsightFace를 활용한 0.2초 초고속 신원 확인
  • "위험한가?": YOLOv11 Pose 추정 + 생체역학(Biomechanics) 알고리즘 결합
  • "효율적인가?": 경량 모델 + 기하학적 룰로 실시간성 확보
SLIDE 02

기술적 난제: 데이터 부족과 오버피팅

  • 초기 시도: 낙상 이미지로 YOLO Object Detection 학습
  • 한계:
  • CCTV 각도(High-angle)에 맞는 낙상 데이터 부족
  • 특정 자세로 과적합(Overfitting) 발생

SLIDE 06

Rule 1: 박스 비율 검사 (Aspect Ratio)

  • 기준: Width > Height * 0.9
  • 의미: 서 있으면 길쭉, 누우면 납작

SLIDE 16

얼굴 인식 프로세스 (Face ID)

  1. Face Detection: RetinaFace로 얼굴 영역 검출
  2. Feature Embedding: ArcFace로 512차원 벡터 생성
  3. Vector Matching: 코사인 유사도 비교
  4. Authorization: 유사도 0.5 이상 승인

핵심 코드 (낙상 판단)

def check_fall_rule(bbox, kpts):
    x, y, w, h = bbox

    # Rule 1: 박스 비율
    if w > h * 0.9:
        return True

    # Rule 2/3: 어깨-골반 관계
    shoulder_y = (kpts[5].y + kpts[6].y) / 2
    hip_y = (kpts[11].y + kpts[12].y) / 2
    if shoulder_y > hip_y:
        return True

    if abs(shoulder_y - hip_y) < h * 0.2:
        return True

    return False
